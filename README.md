# Restaurant Demo

A simple restaurant landing page demo built with HTML, CSS, and JavaScript.

## Files

- `index.html` — main page structure
- `css/style.css` — core styling
- `css/sections.css` — section layout styles
- `css/contact-footer.css` — contact and footer styling
- `js/main.js` — JavaScript behavior and interactions

## How to use

1. Open `index.html` in your browser.
2. Or use a local server if you want a more realistic development experience.

## Notes

This project is ready to be hosted as a static website and can be extended with additional pages, menu items, or animations.
